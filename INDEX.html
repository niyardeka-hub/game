⚔️ GUN ARENA ⚔️

2-Player Real-Time Online Shooter

✅ PHASE 1 COMPLETE - MVP READY

📋 Project Overview

Gun Arena is a real-time 2D side-scroller multiplayer shooter built with React, Node.js, and Socket.io. Two players compete in a confined arena with movement, aiming, shooting, HP management, and ammo mechanics.

✨ Implemented Features

✅ Multiplayer
  • Create/Join rooms (2 players max)
  • Real-time synchronization (60 FPS)
  • Server-authoritative game logic
  • Player disconnect handling
✅ Gameplay
  • WASD movement with boundaries
  • Mouse aiming and angle synchronization
  • Click-to-shoot with rate limiting
  • 30-round magazines with auto-reload
  • 100 HP per player
  • Bullet collision detection (server-side)
  • Victory detection
✅ UI/UX
  • Neon cyberpunk visual style
  • HTML5 Canvas rendering
  • Real-time HP bars
  • Ammo counter with reload indicator
  • Crosshair and player targeting
  • Game over screen
  • Responsive lobby interface
✅ Anti-Cheat
  • Server validates all collisions
  • Server applies all damage
  • Client cannot modify HP
  • Shot rate limiting

🚀 Quick Start

  1. Run setup: setup.bat (Windows) or bash setup.sh (Mac/Linux)
  2. Terminal 1: cd backend && npm start
  3. Terminal 2: cd frontend && npm start
  4. Open http://localhost:3000
  5. Play! (Use WASD to move, Mouse to aim, Click to shoot)

💡 Key Design Decisions

  • Server-Authoritative: Server is the single source of truth for game state
  • 60 FPS Game Loop: Smooth real-time synchronization
  • Side-Scroller: Easier to implement than top-down with accurate positioning
  • Simple Mechanics: MVP focuses on core gameplay - add complexity later
  • Canvas Rendering: Direct pixel control without game engine overhead

⚠️ Important Notes

  • All collision detection happens on the server (prevents cheating)
  • Damage is applied server-side (clients cannot modify HP)
  • Latency is normal and expected (100-200ms typical)
  • Run backend and frontend in separate terminals
  • Use Chrome/Edge for best performance
